Before you search

Option A: Direct DN42 Network Access
  1. Connect this device to DN42.
  2. Trust the certificate authority used by your DN42 search endpoint.
  3. Set the endpoint in Settings if you use a search service other than Baaka.
Option B: Web Proxy Gateway
  1. You can configure a DN42 Web Proxy Gateway in the extension settings.
  2. You can use our public proxy gateway: https://proxy.dn42.tianyibrad.com/
